# ponka.ai — подключение Gemini Omni Flash

Сайт использует официальный Google GenAI SDK и модель `gemini-omni-1.1-flash` через Interactions API.

## Перед запуском
Нужен API-ключ с доступом к Gemini API. Получай его через Google AI Studio: https://aistudio.google.com/apikey

**Не вставляй ключ в HTML, не публикуй его и не отправляй в чат.** Он хранится только в локальном `.env` на сервере.

## Запуск на компьютере
1. Установи актуальный Node.js (LTS).
2. Распакуй архив и открой терминал в папке `ponka-ai`.
3. Установи зависимости:
   ```bash
   npm install
   ```
4. Создай файл `.env` на основе `.env.example` и замени значение `GEMINI_API_KEY` своим ключом.
   - Windows PowerShell: `Copy-Item .env.example .env`
   - macOS/Linux: `cp .env.example .env`
5. Запусти:
   ```bash
   npm start
   ```
6. Открой `http://localhost:3000`.

## Что работает
- Форма отправляет описание на `/api/generate`.
- Сервер вызывает `gemini-omni-1.1-flash` через `@google/genai`.
- В ответе видео отображается в плеере и его можно скачать.
- Есть простое ограничение частоты запросов.

## Важно
- Реальная генерация может требовать включённого биллинга/доступа к модели; доступ зависит от аккаунта и региона.
- Генерация видео может стоить денег. Проверь квоты и цены в Google AI Studio перед использованием.
- Форма регистрации на главной пока демонстрационная. Она не создаёт реальные аккаунты и не связана с Google Flow.
- Для публикации в интернете потребуется хостинг Node.js, HTTPS, настоящая авторизация, лимиты на пользователя, защита от злоупотреблений и настройка политики хранения данных.
- Это интеграционный шаблон; фактическую генерацию можно проверить только после добавления собственного API-ключа и запуска сервера.

Документация:
- https://ai.google.dev/gemini-api/docs/omni
- https://ai.google.dev/gemini-api/docs/models


## Если появляется `Failed to fetch`
Это обычно означает, что браузер не может связаться с сервером. Один HTML-файл не может сам вызывать `/api/generate`, если сервер не запущен.

1. На компьютере открой терминал в распакованной папке проекта.
2. Выполни `npm install`, затем `npm start`.
3. Открой именно `http://localhost:3000` (не `file:///.../index.html`).
4. Проверь `http://localhost:3000/api/health`. Должен появиться JSON с `ok: true`. `apiKeyConfigured` должен быть `true` после настройки `.env`.
5. Если тестируешь с телефона, `localhost` телефона — это сам телефон. Запусти сервер на ПК и открой его через локальный IP компьютера в той же Wi-Fi сети, либо размести сервер на Node.js-хостинге с HTTPS.
